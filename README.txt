STUDYPILOT ENHANCED - SETUP
1. Extract this ZIP.
2. Open the extracted StudyPilot-Enhanced folder in VS Code.
3. Open Terminal in VS Code.
4. Run: npm install
5. Run: npm start
6. Open http://localhost:3000 in your browser.
7. Register a new account, then use the features.
Your SQLite database file studypilot.db is created automatically.
Features: login/register, task planner, attendance tracker, marks analytics, study resource links, focus timer.
Note: The CGPA shown is only an estimate, not an official university calculation.
